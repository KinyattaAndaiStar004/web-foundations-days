## QuickNotes

QuickNotes is a simple web-based note-taking application that allows users to create, organize, search, and delete notes. Each note can be assigned to a category such as Personal, Work, or Study. The application also saves notes in the browser using localStorage, so notes remain available after refreshing the page.

## Features

- Add new notes
- Categorize notes as Personal, Work, or Study
- Display notes as cards
- Delete individual notes
- Clear all notes
- Search notes by text
- Validate notes before adding them
- Limit notes to 200 characters
- Display the number of saved notes
- Save notes using localStorage
- Load saved notes when the page opens
- Responsive design for smaller screens

## How to Run Locally

1. Clone or download the project repository.
2. Open the `quicknotes-app` folder in Visual Studio Code.
3. Open `index.html` in a web browser.

You can also use the Live Server extension in Visual Studio Code:

1. Open `index.html`.
2. Right-click inside the file.
3. Select **Open with Live Server**.
4. The QuickNotes application will open in your browser.
