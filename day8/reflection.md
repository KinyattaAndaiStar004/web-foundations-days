# Day 8 Reflection

## What was the most difficult concept, and how did I overcome it?

The most difficult concept in this course was understanding how to prevent two users from purchasing the same seat at the same time. Initially, it was easy to think that checking seat availability on the user interface would be enough. However, I learned that two requests can arrive almost simultaneously. I overcame this by studying database transactions, conditional updates, and unique constraints. I now understand that the database must be the final authority when allocating seats, while caching is mainly useful for improving read performance.

## Which part of my capstone would I improve based on feedback?

Based on the feedback I received while working on my QuickNotes project, I would improve the completeness and organization of the user interface. My earlier About page was missing the required keyboard shortcuts table and feedback form, and it contained duplicated sections. I would improve it by checking every requirement against a checklist, removing unnecessary repetition, testing navigation links, and making sure that all required features are present before submitting. This would help me produce a more complete and professional project.
